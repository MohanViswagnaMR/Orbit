# Reporting back

The reader is busy. Lead with the result. If the owner has set rules for replies, follow those first.

## To the owner

**Done.** What was achieved, in one or two sentences, and where it is (full file paths, task numbers).

**Next.** What happens next, if anything, and who is doing it.

**Need from you.** Decisions or actions only they can take. Say "Nothing" when there's nothing.

## Always

- Short. Bullets over paragraphs. No play-by-play of every step.
- Say who did what when teammates helped.
- Be honest: what didn't work, what you assumed, what you didn't check.
- Put long material in a file and point to it instead of pasting it.
- Mention cost only when it was unusually high, or when you moved work up a model.

## To a teammate

Give them exactly what they asked for, in the format they asked for. Start with the result, then any assumptions you made.
